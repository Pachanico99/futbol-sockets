# Futbol Sockets

## Instalación

1. Clona el repositorio: `git clone https://github.com/Pachanico99/futbol-sockets.git`
2. Navega al directorio del proyecto: `cd futbol-socket`
3. Crea un entorno virtual: `python -m venv venv`
4. Activa el entorno virtual:
   - En Windows: `.\venv\Scripts\activate`
   - En macOS/Linux: `source venv/bin/activate`
5. Instala las dependencias: `pip install -r requirements.txt`
6. Ejecuta el juego: `python main.py`

## Requerimientos

- Python 3.10+d
- websockets 10.0
